# Справочник функций shop-orders

Запускать из редактора **основного** проекта: выбрать функцию в списке
сверху → «Выполнить» → читать «Журнал выполнения».
Все функции без аргументов. Функции с `_` на конце — внутренние, руками не вызывать.

Проекты внутри таблиц (`legacy/*`) ОТКЛЮЧЕНЫ 15.09.2026: код выхолощен,
триггеры сняты. Ничего там не включать.

---

## Ежедневное / частое

| Функция | Что делает | Когда запускать |
|---|---|---|
| `a02_clearCache` | Сбрасывает кеш справочника и ассортимента | После правок в Довіднику ТТ или листе «Ассортимент», если приложение показывает старое |
| `deadlineStatus` | Показывает время Киева и статус всех дедлайнов | Продавец говорит «закрыто, а не должно быть» |
| `z01_checkBakeryToday` | Полная диагностика выпечки: листы, хвост сырого листа, типы дат, строк за сегодня, ассортимент, дни приёма | Первое, что запускать при любой жалобе по выпечке |
| `z02_checkVegToday` | То же по овощам | Первое при жалобе по овощам |
| `z03_checkBreadToday` | То же по хлебу Рома | Первое при жалобе по хлебу |
| `z04_checkNbhzToday` | То же по НБХЗ | Первое при жалобе по НБХЗ |

## Аварийное открытие приёма

Снимает дедлайн до конца дня И чистит метки «уже заказывали».
Точки, у которых строки в листе целы, останутся заблокированы — дублей не будет.

| Функция | Направление |
|---|---|
| `z09_reopenBakeryToday` | Выпечка и кулинария |
| `z10_reopenBreadToday` | Хлеб Рома |
| `z11_reopenNbhzToday` | Хлеб НБХЗ |
| `z12_reopenVegToday` | Овощи |
| `z13_closeBakeryToday` | Вернуть обычный режим (только выпечка) |
| `z14_clearMarksForList` | Снять метки по списку адресов внутри функции. Дедлайн НЕ снимает |

Только дедлайн, без чистки меток: `allowLateVeg`, `allowLateBakery`,
`allowLateBread`, `allowLateNbhz`. Обратно: `closeLateVeg`, `closeLateBakery`,
`closeLateBread`, `closeLateNbhz`.

## Овощи: разовое открытие не по графику (VegOverride.gs)

| Функция | Что делает |
|---|---|
| `v00_setupAll` | Одна кнопка: открыть завтра + поставить сторожа + снять бекап |
| `v01_openVegTomorrow` | Дописывает завтрашний день в колонку Q Довідника всем «вторниковым» точкам. Старые значения сохраняет |
| `v02_restoreVegDays` | Возвращает график как был. Сам вызывается сторожем на следующий день |
| `v03_showVegToday` | Кто именно может заказывать овощи сегодня |
| `v04_installVegGuard` | Ставит триггер `vegGuard` на каждый час |
| `v05_vegBackupNow` | Снимок сегодняшних строк в таблицу-бекап прямо сейчас |
| `v06_createBackupNow` | Создать таблицу-бекап, даже если строк ещё нет |
| `v07_fixVegRawFormat` | ЛЕЧЕНИЕ: дата/время стали числами (46280 вместо даты). Чистит формат, пересобирает отчёт, снимает бекап |
| `v08_checkVegTypes` | Показывает типы значений в колонке A: должно быть `Date`, а не `number` |
| `v09_excludeAlreadyOrdered` | Убирает открытие у точек, которые уже заказали сегодня — защита от двойной поставки |
| `vegGuard` | Триггерная, руками не нужна. Каждый час: бекап, сигнал на почту если строк стало меньше, авто-возврат графика |

Таблица-бекап: только дозапись, никто кроме сторожа в неё не пишет.
Восстановление = копипаст колонок B–H обратно в сырой лист.

## Отчёты

| Функция | Листы |
|---|---|
| `g01_bakeryReport` | Заказы ВК, Сводная ВК, Маршрути ВК — собрать сейчас в любом случае |
| `h01_breadReport` | Заказы, Данные Заказов — собрать сейчас |
| `h03_vegReport` | Замовлення Овочі, Зведена Овочі — собрать сейчас |
| `e03_nbhzExport` | Вивантаження ДД.ММ.РРРР — собрать сейчас |
| `h02_refreshBreadReport` / `h04_refreshVegReport` / `refreshBakeryReports` / `e04_refreshExport` | Триггерные, каждые 5 минут. Пересобирают только если содержимое изменилось. Руками не нужны |

Если отчёт пустой, а строки в листе есть — почти всегда формат даты.
Смотреть `v08_checkVegTypes` / `z01_checkBakeryToday`, лечить `v07_fixVegRawFormat` / `d08_fixRawFormat`.

## Известные слабые места

1. `archiveOneRebuild_()` — `clearContent` + `setValues` под замком направления,
   а `apiAppend_` замок НЕ берёт. Заказ в момент пересборки теряется.
   Лечение: заставить `apiAppend_` брать `dirLockAcquire_` либо перевести
   пересборку на `deleteDimension`, как в `deleteTodayRows_`.
2. Формат наследуется от строки выше (`INSERT_ROWS`). Если первая строка
   данных унаследовала шапку — дата становится числом и приложение
   перестаёт видеть заказы. Так пропали овощи 15.09.
3. По овощам два архива: `_Архів_Овочі` (старый скрипт) и `_Архів`
   (приложение). Слить в один.
4. Старое развёртывание формы овощей отдавало код от 19.08 с живым
   `recordOrder`. Проверять после любых правок в legacy: версия
   развёртывания должна быть свежей, иначе правки не действуют.
