# Справочник функций shop-orders

Запускать из редактора **основного** проекта (не из того, что внутри таблиц):
выбрать функцию в списке сверху → «Выполнить» → читать «Журнал выполнения».
Все функции без аргументов. Имена с `_` на конце — внутренние, руками не вызывать.

Проекты внутри таблиц (`legacy/bakery`, `legacy/bread`, `legacy/veg`) отключены
15.09.2026: код выхолощен, триггеры сняты. Обратно не включать.

**Функции с переменной внутри** помечены значком ✎ — перед запуском надо
открыть код функции и вписать направление или точку. Направления:
`bread` (Хлеб Рома), `nbhz` (Хлеб НБХЗ), `bakery` (Выпечка и кулинария), `veg` (Овощи).

---

## С чего начинать при любой жалобе

| Функция | Что покажет |
|---|---|
| `z01_checkBakeryToday` | Выпечка: все листы таблицы, хвост сырого листа с типами дат, строк за сегодня, ассортимент, дни приёма, что видит приложение |
| `z02_checkVegToday` | То же по овощам |
| `z03_checkBreadToday` | То же по хлебу Рома |
| `z04_checkNbhzToday` | То же по НБХЗ |
| `deadlineStatus` | Время Киева и статус дедлайнов по всем направлениям |
| `d07_showTriggers` | Что стоит в расписании прямо сейчас |

Если в логе строки за сегодня есть, а отчёт пустой — почти всегда формат даты
(колонка A стала числом). Лечение: `v07_fixVegRawFormat` для овощей,
`d08_fixRawFormat` / `g17_fillMissingBakeryDates` для остальных.

## 1. После каждого деплоя (a)

| Функция | Что делает | Когда |
|---|---|---|
| `a01_authorize` | Выдаёт разрешения, проверяет что Sheets API включён | После каждого `clasp push` |
| `a02_clearCache` | Сбрасывает кеш справочника и ассортимента | После правок в Довіднику ТТ или «Ассортимент» |
| `a03_setWebAppUrl` ✎ | Запоминает рабочий URL приложения (вписать внутри, должен кончаться на `/exec`) | После создания НОВОГО развёртывания. После смены версии — не нужно |

## 3. Замеры (c) — в рабочее время не запускать

| Функция | Что делает | Осторожно |
|---|---|---|
| `c01_benchmark` | Скорость bootstrap, heartbeat, загрузки ассортимента | Безопасно |
| `c02_measureWrite` | Реальная стоимость одной записи по всем направлениям | Пишет в листы |

## Известные слабые места

1. `archiveOneRebuild_()` (`Archive.gs`) — `clearContent` + `setValues` под замком
   направления, а `apiAppend_` замок не берёт. Заказ в момент пересборки теряется.
   Лечение: либо `apiAppend_` берёт `dirLockAcquire_`, либо пересборка через
   `deleteDimension`, как в `deleteTodayRows_`. Пока не сделано — `d05` только вне работы.
2. Формат наследуется от строки выше (`INSERT_ROWS`). Если первая строка данных
   унаследовала шапку, дата становится числом и приложение перестаёт видеть заказы.
   Так «пропали» овощи 15.09 — все 15 строк лежали в листе.
3. По овощам два архива: `_Архів_Овочі` (старый скрипт) и `_Архів` (приложение).
   Слить в один.
4. Развёртывание Apps Script прибито к версии кода. После правок в legacy надо
   обновить версию у активного развёртывания, иначе старый URL продолжает
   отдавать старый код. У овощей так висела Версия 22 от 19.08 с живым `recordOrder`.
5. `e05_setupVegDays` и `e07_setupBakeryDays` перезаписывают колонки Q и R целиком —
   конфликтуют с разовым открытием `v01`. Сначала `v02_restoreVegDays`.
6. `f10_clearOffDayOrders` удаляет заказы «не в свой день». После возврата графика
   заказы открытого дня выглядят именно так. По овощам в такие дни не запускать.
