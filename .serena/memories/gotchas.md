# Грабли, на которые уже наступили

Каждая стоила времени. Не наступать повторно.

## .bat с кириллицей + chcp

Батник в UTF-8 с русским текстом и `chcp 65001` внутри **ломает cmd**:
он читает .bat по байтовому смещению, после смены кодовой страницы теряет
позицию и начинает выполнять обрывки текста как команды
(`'Фцы' is not recognized...`), окно мигает и закрывается.

Решение: `МАТРИЦА.bat` — только ASCII, CRLF, 9 строк, всё меню в Python
(`python matrix.py menu`), где юникод работает нормально.

## Комментарии в .gitignore

Запись `apps_script/Claude.gs  # ключ` **не работает**: git считает
шаблоном всю строку целиком. Файл с API-ключом спокойно попал в индекс.
Комментарии — только на отдельной строке. Проверять перед коммитом:
`git diff --cached | grep -cE 'sk-ant-|AIza|ghp_'`.

## Git в подключённой папке

Git создаёт и удаляет временные объекты, а device_bash по умолчанию не
может удалять файлы (`Operation not permitted`) — `git add` молча не
срабатывает. Нужен `device_request_delete_permission` на папку проекта.

## Токен в .git/config

Пушить через временный remote с токеном, после пуша —
`git remote set-url origin https://github.com/...` без токена.
Проверять: `grep -c x-access-token .git/config`.

## Старый процесс в памяти

Дважды: пользователь держал открытым меню / окно UI, запущенное ДО
перестановки файлов, и получал «немає файлу status_update.py» и молча
не работающую кнопку «Пересканувати». **После любой перестановки файлов
или правки путей — просить перезапустить `МАТРИЦА.bat` и окно UI.**

## F5 ≠ пересканирование

Окно новинок читает лист «Товары вне матрицы» — это снимок.
Обновление браузером показывает тот же снимок. Пользователь решил, что
добавленные позиции «не отсекаются». Добавлены: отметка времени снимка
в шапке (жёлтая, если старше 12 ч), подсказка над таблицей и удаление
обработанных строк с экрана сразу.

## clasp не нужен

Пробовал `clasp login --no-localhost` через FIFO — не работает, prompt
читает только из настоящего TTY. И не понадобился: сервисный аккаунт
читает привязанный Apps Script напрямую. См. `mem:apps_script`.

## Sheets API: лист забит под завязку

`insertDimension` падает с `startIndex is larger than current grid size`,
если строк ровно `row_count`. Перед вставкой добирать ёмкость: `ws.add_rows(n)`.

## Поставщик в приходе ≠ поставщик в матрице

`Авангард Дистрибуції` → `Авангард`, `ДЛ Солюшн` → шесть строк `Сигарети_*`.
Брать из `supplier_mapping`, кандидатов выносить в начало списка.

## Замена литералов в patch-скриптах

При правке файлов через python-heredoc: если искомый текст содержит `\\n`
(как в JS внутри python-строки `PAGE`), в шаблоне поиска нужен
raw-литерал `r'''...'''`, иначе не совпадёт. И **писать файл только после
всех замен** — при `assert` на середине изменения теряются целиком.

## Самоубийство pkill

`pkill -f "clasp login"` убивает и сам шелл, который его запустил
(его командная строка содержит паттерн). Exit 143.
