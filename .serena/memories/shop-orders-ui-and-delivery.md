# shop-orders — інтерфейс, доставка продавцям, вивантаження

Доповнення до `mem:shop-orders-overview`.

## Як продавці отримують застосунок

Посилання на `/exec` ставиться на екран телефона лише як закладка —
відкривається вкладкою браузера з адресним рядком. Manifest і service
worker у сторінку `script.google.com` не додати: вона не наша.

Тому в репозиторії є `docs/` — оболонка на GitHub Pages
(Settings → Pages → Deploy from a branch → main → /docs):

- `index.html` — застосунок на весь екран в iframe, `?tt=` прокидується
  всередину, заставка з логотипом, зрозуміла помилка без мережі
- `manifest.webmanifest` — standalone, portrait, назва «Замовлення»
- `sw.js` — мінімальний, потрібен Android для встановлення, дані не кешує
- `app-url.js` — адреса `/exec` одним рядком
- іконки 192/512/maskable, вирізані зі знака-пакета в `assets/logo.png`

Адреса: `https://denbassk.github.io/shop-orders/`, константа `PWA_URL`
у Config.gs. `storeLinks()` віддає посилання саме на оболонку.

В Apps Script для цього потрібен `setXFrameOptionsMode(ALLOWALL)` —
без нього оболонка не вбудує застосунок.

Встановлення: Android Chrome → «Встановити застосунок» (не «додати на
головний екран»); iPhone Safari → «Поділитися» → «На екран Домівка».

**Адреса /exec міняється лише при СТВОРЕННІ нового розгортання.**
Завжди редагувати наявне (олівець) і ставити «Версія: Нова», інакше
доведеться правити `docs/app-url.js`.

## Вивантаження для заводу НБХЗ

`buildNbhzExport()` будує лист «Вивантаження ДД.ММ.РРРР»: маршрут,
адреса, далі колонки по 18 позиціях у порядку листа «Ассортимент».
Беруться ВСІ точки НБХЗ із Довідника — де замовлення немає, стоять нулі,
як у файлі заводу.

Оформлення: назви горизонтально з перенесенням, сітка, смужки через
рядок, нулі блідо-сірі а замовлене чорним жирним, закріплені шапка і
дві перші колонки, фільтр.

**`Файл → Завантажити` тягне ВСЮ книгу.** Один лист віддає посилання
`.../export?format=xlsx&gid=...` — воно лежить на окремому листі
«Завантаження», оновлюється щодня само.

Оновлення: `refreshNbhzExport()` кожні 15 хв з 6:00 до 20:00 перезбирає,
якщо була позначка `nbhz_export_dirty` або листа за сьогодні немає.
Плюс повна збірка о 18:00.

## Зміни в замовленні після дедлайну

Два режими в жовтій плашці після дозволу закупниці:
- «Дозамовити» — нові рядки додаються
- «Переробити все» (`mode: 'replace'`) — сьогоднішні рядки точки
  видаляються через `Sheets.Spreadsheets.batchUpdate` під замком,
  замовлення пишеться з нуля. Так прибирають зайву позицію або
  міняють кількість.

`cancelTodayOrder()` / `f07` — прибрати замовлення точки повністю
разом із позначкою «вже замовляли».

## Дрібниці інтерфейсу

- Індикатор завантаження — SVG-коло з анімованим штрихом. Старий,
  зібраний із бордерів, давав темну риску збоку. Підписи: «Хвилинку…»
  на старті і випадкова фраза з `WAIT_MSG` при завантаженні товарів.
- Облікові номери ТТ прибрані з інтерфейсу — вони не за алфавітом і
  плутали. Лишились лише у службовому `d03_storeLinks`.
- Порожній асортимент більше не білий екран: продавцю пишеться, що всі
  позиції на стопі.
- `renameStore()` / `f08` — перейменувати ТТ. Міняється ЛИШЕ колонка B
  Довідника. Адреса в колонці C — це id точки, від неї залежать статуси
  і дозволи, тому її не чіпати.

## Інструкція продавцям

Коротка, російською, без технічних деталей. Ключове: вибрати свій адрес,
напрямок, кількості, перевірити низ екрана, «Відправити», дочекатись
зеленої галочки. Не тиснути двічі, не оновлювати сторінку. Запізнився —
«Попросити дозвіл», запит іде Світлані (кулінарія — Юлі), кнопка
вмикається сама, дозвіл 30 хвилин.
